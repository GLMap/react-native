# @globus-software/glsearch

Independent glsearch module for React Native Fabric / Expo development builds.
Depends only on @globus-software/glmap-core; other feature packages are optional.

Install this package and list `@globus-software/glsearch` in Expo's plugins. Rebuild
the development client; Expo Go is not supported. Native GLMap 2.2.0 and modular
SwiftPM Core are required. `GLMAP_SDK_DIR` is an explicit local SDK override during
release preparation. Android API 24+, iOS 16.4+.

This package has not been published. Native SDK/data licenses remain applicable.
